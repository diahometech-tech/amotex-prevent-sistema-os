# Amotex Prevent — Sistema de OS

App interno de gestão de ordens de serviço para a Amotex Prevent (manutenção de bombas e caixas d'água em condomínios). Ver `CLAUDE.md` para o histórico do fork e o status atual, e o repositório [`amotex-prevent-infra`](https://github.com/diahometech-tech/amotex-prevent-infra) para o contexto completo do projeto (PRD, modelo de dados, infraestrutura).

## Stack

Next.js 16 + Postgres, deploy via PM2 (ver `deploy/`).
